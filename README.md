# Covid-19 Exploratory Data Analysis --- SQL

About the project:

		The goal of this project is to practice working with real-world data using sql. By using various queries I tried to find patterns and insights like :-
		  
				1. how many people got affected
    
				2. death percentages in different places
    
				3. continental aggregates and rate of infected people
    
				4. global insights

Two main datasets used :-

		- covid deaths data
  
		- covid vaccinations data
  
(both files were combined using joins to get complete information.)

tools used:-

	1. SQL – Data exploration, querying, filtering, aggregations, joins, and analysis
    2. SQL Workbench – Database environment used to execute SQL queries
    3. Excel / CSV – Source data files and initial data handling
